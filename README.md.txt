# KiCad Custom Libraries

A small collection of custom KiCad footprints and schematic symbols for electronic modules.

## What's Included
- **Footprints:** Custom PCB footprints.
- **Symbols:** Custom schematic symbols.

## How to Use
1. Download the repository and extract it.
2. Add the `.pretty` folder in KiCad's Footprint Libraries.
3. Add the `.kicad_sym` file in KiCad's Symbol Libraries.
4. Start using the components in your designs.

More components and libraries will be added over time.

**Note:** Always verify component dimensions and pin connections before PCB manufacturing.
